# CodeSafe

**Lightweight Version Control for Sketchware Pro**

CodeSafe is a standalone Android application developed by **OzDroid Software** to help Sketchware Pro developers manage source-code revisions without the complexity of traditional version-control systems.

Built around a local SQLite database, CodeSafe provides project and file management, commit history, version reconstruction, and visual comparison of source-code changes.

## Features

- **Project and File Management** — Organise and track Java source files.
- **Commit History** — Save revisions with descriptive commit messages.
- **Efficient Version Storage** — Use compressed snapshots and incremental diffs.
- **Version Reconstruction** — Reconstruct earlier versions from stored revision data.
- **Visual Diff Viewer** — Compare revisions side by side with Java syntax highlighting and colour-coded additions and deletions.
- **Database Backup and Restore** — Protect and recover your version-control database.
- **Offline Operation** — No internet connection or remote repository required.

## Installation

1. Download the APK from the [Releases](../../releases) section.
2. Install the APK on your Android device or emulator.
3. Launch CodeSafe and begin managing your projects and source files.

Android may require permission to install applications from outside the Play Store.

## About

CodeSafe was created to provide Sketchware Pro developers with a practical, lightweight way to track source-code changes and review previous revisions.

It is designed for individual developers and is not intended to replace collaborative version-control systems such as Git.
